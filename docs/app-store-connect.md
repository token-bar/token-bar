## Description

```
TokenBar is a macOS menu bar app that unifies AI usage across multiple providers in one place. See tokens, credits, spend, quotas, and burn rate at a glance—without opening separate dashboards.

Connect the providers you use, pick how usage appears in your menu bar, and get native alerts before you hit a limit. Your credentials stay in the macOS Keychain. Usage history and preferences stay on your Mac.

MENU BAR
• Live usage in the menu bar—percentage, progress bar, spend, credits, burn rate, or multi-provider aggregate
• Compact design that stays out of your way
• Manual refresh or automatic updates on your schedule

PROVIDERS
• Cursor Personal — session from your dashboard
• Cursor Team — admin API key
• OpenAI — organization Admin API key
• Anthropic — Admin API key
• Custom HTTP proxy — optional bearer token + canonical JSON endpoint
• Demo Provider — simulate usage for testing without real accounts

FORECASTING & ALERTS
• Burn rate and exhaustion estimates from local history
• macOS notifications at usage thresholds and forecasted exhaustion
• Customize alert preferences in Settings

WIDGET
• Notification Center / Desktop widget with cached usage snapshots
• Glanceable status without opening the app

PRIVACY
• No TokenBar account required
• Credentials stored in Keychain
• Diagnostics export never includes secrets
• No ads, analytics, or third-party trackers

TokenBar is built for developers and teams who use more than one AI provider and want a single, privacy-first view from the menu bar.

Requires macOS 26 (Tahoe) or later.
```

## App Review notes

```
TokenBar is a macOS menu bar app (no Dock icon). After launch, click the menu bar icon to open the panel and access Settings.

In Settings, users connect AI providers (Cursor Personal, Cursor Team, OpenAI, Anthropic, or a custom proxy) and choose how usage appears in the menu bar—percentage, spend, credits, burn rate, or a multi-provider aggregate. Usage can be refreshed manually or on a schedule.

To test without real provider accounts: open Settings → Providers → add “Demo Provider” (no credentials required) → Refresh Now. Users can also enable usage alerts and add the TokenBar widget from Notification Center after the first refresh.
```
